Phase 2 — Data architecture

Before adding more functionality, establish one source of truth.

Currently you have things like:

const [applications, setApplications] = useState(applicationData);

We'll eventually move toward:

App Data
│
├── applications
├── profile
├── resumes
├── preferences
├── settings
└── calendar events

For the first working version:

localStorage → React state → UI

Later:

Supabase/Firebase → React state → UI

This prevents the mess where Dashboard has one application array and Applications has another.
